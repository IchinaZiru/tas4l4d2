About

本プラグインは、前マップの基準点 P1(pre) と 次マップの基準点 P2(aft) を1度記録し、 Δ = P2 − P1 を保存します。以降は任意の現在位置 P に対して Forward: P+Δ / Reverse: P−Δ を瞬時に計算・表示・テレポートできます。

Install

  1. コンパイル済み l4d2_transit_tools.smx を cfg/sm_server/plugins に配置。
  2. 初回のみ、保存先フォルダ cfg/sm_server/data/ を作成（空で可）。
  3. サーバ再起動。ConVar自動cfg cfg/sourcemod/l4d2_transit_tools.cfg が生成されます。

Module (Data & Visualization)

項目 内容
保存データ Δ = P2 − P1 と、参考として pre/aft の両方を KeyValues で保存。
以後は Δ が見つかればコマンド群が機能します。
可視化 現在位置P（縦ビコン） / 写像先（P±Δ） / Forward矢印 / Reverse矢印 / pre(P1) / aft(P2)
依存 <sourcemod>, <sdktools>, <sdktools_tempents>, <halflife>
ビーム用: materials/sprites/laserbeam.vmt, materials/sprites/glow01.vmt

Chat Commands

Command Syntax 説明
!tpre sm_tpre 現在位置を P1(pre) として記録。青系の縦ビコンを表示。
!taft sm_taft [nextmap] P2(aft) を記録し Δ を保存。info_changelevel.m_mapName が無いカスタムは引数で nextmap を指定。
!transit sm_transit [nextmap] Forward: P → P+Δ を計算・表示。P→(P+Δ) のビーム描画。
!transit_tp sm_transit_tp [nextmap] Forward をテレポートで適用（P ← P+Δ）。
!rtransit sm_rtransit [prevmap] Reverse: P → P−Δ を計算・表示（Δ は prevmap → 現在 のペアから取得）。
!rtransit_tp sm_rtransit_tp [prevmap] Reverse をテレポートで適用（P ← P−Δ）。
!tvis sm_tvis pre / aft / Δ と、現在の P と写像先の関係を一括可視化。

User Workflow

  1. （前マップ）セーフルーム等で !tpre → P1 保存。
  2. （次マップ）ロード直後に動かず !taft（または !taft <nextmap>）。Δ が保存される。
  3. 検証：!transit / !transit_tp（順方向）、!rtransit / !rtransit_tp（逆方向）。
  4. いつでも !tvis で pre/aft/Δ と P±Δ の見た目を再確認。
注意: テレポートは同一マップ内の相対移動です。壁抜けや落下に注意し、必要に応じて noclip 等で検証してください。

ConVars

Name Default 説明
l4d2_transit_beam_time 6.0 ビーム/グロウの寿命（秒）。
l4d2_transit_beam_width 4.0 ビームの太さ。
l4d2_transit_beam_height 160.0 縦ビコンの高さ。

ファイル: cfg/sourcemod/l4d2_transit_tools.cfg（自動生成）

Data File Format

保存先: cfg/sm_server/sourcemod/data/l4d2_transit_pairs.cfg（KeyValues, 自動生成/更新）

"TransitPairs"
{
  "<preMap>"
  {
    "<nextMap>"
    {
      "pre"   "x y z"
      "aft"   "x y z"
      "delta" "x y z"
    }
  }
}

基本は !tpre → （遷移） → !taft で作成。必要なら手編集も可。

Troubleshooting

症状 原因/対処
「Δ 未登録」 マップペアのΔが未作成。!tpre → （遷移） → !taft を実行。
次マップ名が分からない info_changelevel が無い/特殊。!taft <nextmap> / !transit <nextmap> のように明示。
TPで壁の中/落下 Δは相対座標差でありジオメトリ考慮なし。検証は noclip 推奨。公開サーバでは権限制御を。
ビームが見えない マテリアルの precache 失敗や ConVar 値の影響を確認。ログ/ConVarを点検。
