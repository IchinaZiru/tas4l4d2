# docs/

プロジェクトの **ドキュメント一式** を配置します。  
ユーザー向けガイド、API 仕様、AM フォーラム投稿用の草稿などを格納します。

## 推奨ファイル
- `README-en.md` / `README-ja.md` : 概要・導入・依存・使い方
- `api_reference.md` : コマンド / ConVar / フォワード / ネイティブの一覧
- `usage_examples.md` : 具体的なセットアップ・チュートリアル
- `changelog.md` : 変更履歴（SemVer 準拠）
- `troubleshooting.md` : よくある問題と解決策

## AlliedModders 連携
- フォーラム投稿文のドラフトをここで管理（英語推奨）
- ダウンロードは GitHub Releases（.smx / .sp / cfg / translations）へのリンクを案内
