Finale Analyzer — Module & Menu

L4D2 のフィナーレを自動監視し、CI/Tank スポーンを可視化＆ダンプ保存。波（PANIC/PAUSE/TANK/DELAY）も自動セグメント。

About

  • Finale開始を自動検知し、その瞬間から CI/Tank のスポーンを収集・可視化・保存。
  • CI の湧きレートと無湧き時間から PANIC/PAUSE/DELAY を推定、TANK は専用区間。
  • 結果は ems/final_stage/<map>_dump.txt に追記。
  • ゲーム内 Panel メニュー（数字キー 1–5）で操作：sm_fa / fa_menu / チャット !fa

Version: v1.0.1 　Requires: SourceMod 1.11+　Deps: <sdktools> <sdkhooks>

Install

  1. finale_analyzer.smx を addons/sourcemod/plugins/ に配置。
  2. マップ変更 or sm plugins load finale_analyzer。
  3. 初回実行時に ems/ と ems/final_stage/ を自動作成します。

Usage（Menu & Commands）

操作やり方説明
メニュー表示 sm_fa / fa_menu / !fa Panel メニューを開きます（数字キー 1–5 で選択）。
メニュー項目 1: Start/Stop
2: Draw ON/OFF
3: Dump Now
4: Clear Markers
5: Exit		 1: 監視の開始/停止。2: DebugDraw の切替。
3: 現時点の統計をダンプに追記（波は一旦閉じて即再開）。
4: 画面の描画をクリア（DebugDrawClear()）。
コンソール fa_dump_now メニューの「Dump Now」と同等。マップごとのダンプに追記します。
Note: 本プラグインは ClientMenu 用の .cfg は不要です。メニューは プラグイン内の Panel で完結します。

ConVars

NameDefault説明
fa_enable1プラグイン有効化 (1/0)。
fa_draw1DebugDraw 可視化 ON/OFF。
fa_draw_time15.0描画の寿命（秒）。
fa_panic_rate1.5PANIC 判定の CI 湧き/秒しきい値。
fa_pause_gap4.0PAUSE 判定の連続無湧き秒数。

Dump Output

保存先：ems/final_stage/<map>_dump.txt（例：c2m5_concert_dump.txt）
==== Finale START (event:finale_start) map=c2m5_concert time=12345.678 ====
WAVE_START 1 DELAY time=12345.678 reason=low-rate
CI 1234.5 678.9 12.3 wave=1 kind=DELAY time=12346.100
TANK_SPAWN #1 1200.0 600.0 20.0 time=12360.000
WAVE_END 1 DELAY dur=14.322 ci=27 time=12360.000
WAVE_START 2 TANK time=12360.000 reason=tank_spawn
TANK_KILLED time=12390.000
WAVE_END 2 TANK dur=30.000 ci=0 time=12390.000
==== Finale STOP (finale_end) time=12450.000 ====

例：PANIC は高レート湧き、PAUSE は連続無湧き、TANK は Tank 在存区間として扱われます。

How It Works

項目内容
Finale検知 finale_start / finale_win / mission_lost / finale_vehicle_leaving をフック。
加えて trigger_finale の I/O（FinaleStart / FinaleEscapeStart）。
CI検知 infected エンティティの SDKHook_SpawnPost で座標取得→可視化（円＋テキスト）・ダンプ。
波推定 0.5秒ごとに直近の湧き数をバケット集計。
rate ≥ fa_panic_rate → PANIC、連続無湧き ≥ fa_pause_gap → PAUSE、その他は DELAY。
Tank は tank_spawn〜tank_killed を TANK 区間として扱う。
可視化 VScript の DebugDrawCircle / DebugDrawText を AcceptEntityInput(0,"RunScriptCode") で呼出。寿命は fa_draw_time。
CI / TANK（ラベル付）を描画。

Troubleshooting

症状原因 / 対処
メニューが出ない sm plugins list でロード確認。エラーログ（addons/sourcemod/logs/）を確認。権限環境では管理フラグを付与。
ダンプが生成されない ems/ と ems/final_stage/ の書込権限を確認。Finale 監視が開始されているか（メニューの状態）確認。
描画が見えない fa_draw 1 を確認。描画は時間で消えるため fa_draw_time を調整。必要に応じて「Clear Markers」後に再確認。
波の判定が粗い 独特な湧き方のマップではしきい値調整が必要。fa_panic_rate / fa_pause_gap を調整。
