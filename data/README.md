# data/

**記録/再生データやランタイム生成物** を置くフォルダです。  
大容量データはリポジトリに含めず、サンプル最小限＋ `.gitignore` 運用を推奨します。

## 構成例
```text
data/
├─ movements/           # Movement Reader 形式の記録ファイル
│  └─ examples/
│     ├─ run3.txt
│     ├─ gl3.txt
│     └─ bile3.txt
└─ logs/                # プラグインが出力するログ（任意）
```

## 注意点
- 実運用の大容量ファイルは配布対象外にし、パス規約のみ文書化
- センシティブなデータ（内部環境の絶対パス 等）はコミットしない
